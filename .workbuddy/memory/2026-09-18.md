## 第四轮（用户指定站点实采故事 · 已交付）

用户提供站点 https://www.yigushi.com/gushi/ ，据此实采。**产出 `docs/故事采集报告.md`**。

**结果**
- 站点结构：Destoon CMS，UTF-8，robots.txt 只禁 `/api/ /install/ /member/`，`/gushi/` 允许抓。列表 `/gushi/{cat}/list{N}.html`，详情 `/gushi/{id}.html`

- 失败 36 篇全是「正文<80字」极短残页，非网络故障
- 落到 `var/stories/{12个中文分类}/`，每篇一个 `{id}-{标题}.md`，YAML Front Matter + Markdown
- 数据：`_urls.jsonl`（17286）、`_analysis.jsonl`（17250 全量分析）、`分级清单.md`、`_不合适清单.md`、`_failed.jsonl`

**工具**
- `tools/crawl_stories.py`：**纯标准库**（urllib + ThreadPoolExecutor），不装 requests/bs4。支持 `--list-only / --detail-only / --retry-failed / --cat / --limit / --stats`，幂等（已落盘按 id 跳过）
- `tools/analyze_stories.py`：分级 + 适宜性筛查，产出上面三个文档

**踩坑 6：字表存在 568 个跨阶段重复字**
`build_stages.py` 里当多个 S 阶段种子词不足 200 字时都从 `rest[0:]` 起点补齐 → 重复取同一批字，148 字同时属于多个阶段（国/这/为/以/要 同在 S1–S5）。后果是这些字被算作最晚阶段，**人为抬高所有含它们的文章分级**。修复：始终从 `rest[i:i+need]` 切并累加 i；加运行时断言。修复后 **8103 字零重复**，S5 起点即出现可读篇目。

**踩坑 7：适宜性词库误杀率过高**
初版把 鬼/坟/傻子/王八 放拦截级 → 误杀 19%（3263/17250），抽查发现《妈妈赶走了"鬼"》《乌龟给老鹰的教训》（王八=乌龟）等大量正常篇目被误伤。改两级：拦截只留明确血腥暴力/成人/粗口/毒品（2450 篇），鬼怪悼念类降为「家长确认」。可用篇数 7949 → **9714**。

**踩坑 8：分级判据过严**
初版要求正文每字都在目标阶段内（100% 覆盖），1 个生僻人名就把整篇推到 X 阶段。改「98% 用字覆盖」后最低门槛从 G2 降到 S5，分布合理。

**⚠️ 核心结论（务必记住）**
这批故事是**通用读物不是分级读物**，分级分布 S5=1 / G1=12 / G2=48 / G3=176 / G4=421 / G5=794 / G6=1314，累计到 G6 才 2766 篇，**S0–S5（学前）几乎为零**。
→ 落地方式只能是**亲子共读 / TTS 朗读**（<400字短篇 3280 篇可用），**不能指望孩子自主阅读**。
→ 若要覆盖学前自主阅读，必须追加「控字改写」管线（把 800 字原文缩写成 500–1500 字、限制在 S5 的 1155 字内）。

**授权**：源站内容为网络转载无开源协议，`license` 字段如实标记「转载自网络，家庭内部学习使用」。家庭自用 OK；**未来对外提供服务须整批移除**（`source`/`source_url` 字段已保留便于批量清理）。

## 环境注意事项

- 该环境网络下载很慢（约 25 KB/s），66MB ECDICT 需 ~45 分钟；用 `curl -C -` 断点续传，配合后台任务
