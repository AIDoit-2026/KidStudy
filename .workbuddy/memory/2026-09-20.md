# 2026-09-20

## 产出：docs/开发设计文档.md（v1.0，待审核）

编码阶段的落地蓝图，基于已完成的采集资产与需求规划文档收敛而成。要点：

- **架构**：单机 Docker Compose（Caddy + api + worker + PostgreSQL16 + 本地卷），无 Redis、无 MQ、无 PWA。三个 Go 二进制来自同一份代码：`cmd/api`、`cmd/worker`、`cmd/importer`。
- **后端模块**（`server/internal/feature/`）：auth / children / content / practice / mastery / report / print / parent / review / crawl，每个模块固定 `handler.go + service.go + repository.go + model.go`；handler 不写业务、service 不 import net/http、跨模块只走 service 接口注入。platform 层提供 apperr / logger / server / middleware / postgres / storage / sse。
- **数据模型**：身份域（parents/children/refresh_tokens/qr_login_sessions/login_audit）、内容域（stages 24 阶段 / knowledge_points / hanzi 8103 + hanzi_words / en_words 1803 / en_sentences / stories 18913 + story_pairs 831 / videos / math_templates / content_review）、学习域（mastery_records / learning_sessions / session_items / answer_logs / wrong_book_entries / daily_stats / badges）、系统域（parent_settings / jobs）。
- **7 条核心交互时序**：二维码扫码登录（SSE 四事件）、今日任务编排（复习+错题优先+新学+专项）、答题判分、简化 SM-2 与错题本、护眼与时长控制（前端计时、后端权威）、打印中心（模板→job→题面快照→@media print / chromedp PDF）、内容审核与导入管线（var/ → importer → pending → published）。
- **待拍板 6 项**：公开注册是否关闭（建议关闭，用邀请码）、S0–S5 自主阅读缺口是否做控字改写（建议先只做亲子朗读）、TTS 时机（建议先用 Web Speech API，M4 再换预生成）、sqlc vs 手写 pgx（建议 sqlc）、默认节奏（标准：语文 6 字/数学 2 档/英语 5 词每日）、answer_logs 是否分区（建议首期不分区）。

## 审核结论（用户已拍板，写入设计文档 §9）

1. 关闭公开注册（首次启动 BOOTSTRAP_INVITE_CODE 建号）
2. 故事只做亲子朗读 + TTS，不做控字改写
3. TTS 先用 Web Speech API（M2），预生成音频 M4；笔顺 M2 落地
4. 用 sqlc
5. 标准节奏**只作基准线不设闸门**：不限制每日学习次数与进度，可提前学下一日；统计真实速度与标准偏差、每日标准内容的重复学习次数，供家长看整个周期的速度变化与学习效率
6. `answer_logs` 不分区
7. 新增多孩对比：同家长下多孩的学习曲线/速度/重复次数/正确率/时长对比，默认按「学习日序号」对齐（公平），可切自然日期；只并列不排名
8. 每日完成判定 = 混合制：客观题程序判定（completed_by=auto），主观项（跟读/朗读/讨论/纸质）家长一键确认或打分，兜底手动标记（completed_by=parent）；设置项 require_parent_confirm 默认关
