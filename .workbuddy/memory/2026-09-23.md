## 关键经验

- **`/print/jobs/{id}/data` 返回 `{data,meta}` 信封**：冒烟首跑没拆包，items 恒判为 0，
  误以为重印没复现。实际是对断言读错层。
- **校验类错误是 422 不是 400**（`apperr.BadRequest`→VALIDATION_FAILED）；冒烟期望写错了两处。
- **`vite build` 被沙箱拦**：它清 `web/dist/assets` 触发 bulk-delete 守卫；改用
  `tsc --noEmit` 当前端编译闸门，要出包就改 `--outDir`。
- govulncheck 安装：`go install golang.org/x/vuln/cmd/govulncheck@latest`（GOPROXY=goproxy.cn 可下）。
  升级依赖按老约定 `GOTOOLCHAIN=local` + `go get <mod>@<ver>`，go 指令稳住 1.27.1。
- 大字号回归真因：全屏遮罩是 `fixed inset-0 + justify-center`，内容超高被顶出视口且滚不动
  （休息页还锁了 body 滚动）；改成「外层 overflow-y-auto + 内层 min-h-full」。

### 写 README 时核实到的关键事实
- 三个入口：`cmd/api`（`-migrate` / `-rollback`）、`cmd/worker`（日汇总 + `-print[-loop]`
  + `-purge[-loop]`）、`cmd/importer`（`-data` / `-only stages|hanzi|words|stories|plans`）。
- 生产强校验（`APP_ENV=production`）：`COOKIE_SECURE` 不能 false、`BASE_URL` 及各
  `CORS_ALLOWED_ORIGINS` 必须 https。
- **反代场景必须 `TRUSTED_PROXY=true`**，否则 `RealIP` 不读 XFF，限流按 Caddy 的 IP
  分桶 → 所有用户共用一个桶，登录限流会误伤全体。
- `STORAGE_DIR` 默认 `../var/storage`（相对 server/），换工作目录启动必须给绝对路径。
- 前端 `VITE_API_BASE_URL` 是**构建期**注入；同域部署可用相对路径 `/api/v1`。
