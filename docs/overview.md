## 文档覆盖内容

1. 项目定位、差异化、明确不做的事
2. 角色与三大典型使用场景
3. 功能需求：三学科内容体系、练习引擎、评价机制（间隔重复 + 星级 + 错题本）、进度记录与报表、打印中心、护眼与四档响应式、账号与二维码登录、家长控制、爬虫子系统
4. 非功能需求：性能、安全、儿童隐私、可观测
5. 技术架构：Go（chi + pgx + sqlc + slog）/ React（Vite + TanStack Query + Tailwind）/ 目录结构与分层铁律
6. 核心数据模型（20+ 张表）
7. REST API 端点清单与统一响应/错误码约定
8. M0–M7 开发里程碑
9. 风险与合规（版权、爬虫合规、儿童个人信息、沉迷）
10. 三个附录：环境变量清单、MarkItDown 导入通道、数学难度阶梯

**story 模块的关键约束**：17,250 篇最低可读阶段集中在 G3–G9，**S0–S5（学前）仅 1 篇**。源站是通用读物而非分级读物，因此这些故事的落地方式是**亲子共读 / TTS 朗读**，而非孩子自主阅读。若要做自主阅读，需额外增加"控字改写"管线。

## 需要用户决策的遗留项

1. **故事怎么用**：亲子朗读（立即可用）vs 控字改写填补 S0–S5 空缺（需内容管线）
2. **组词/故事 S0–S5 人工复核** 的时机（约 1,120 字，家长后台勾选）
3. 默认学习节奏：标准（对齐 2022 版课标）还是加速
4. 配图方案：CC0 图库自动匹配 vs AI 生成统一风格插画
