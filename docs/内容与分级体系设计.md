# KidStudy · 内容与分级体系设计

> 本文是《需求规划文档》的配套细化，回答「学什么、分几段、每段多少、按什么顺序」。
> 前置结论：字库容量按《通用规范汉字表》8105 字采集；学习阶段按儿童实际节奏切分。

---

## 一、汉字字库：总量与分层

### 1.1 字库来源与分层

采用教育部《通用规范汉字表》（2013）作为字库骨架，天然分三级，正好对应我们的需求：

| 层级 | 字数 | 定位 | 是否作为"学习目标" |
| --- | --- | --- | --- |
| 一级字（常用字） | 3500 | 基础教育必需 | ✅ 是 |
| 二级字（次常用） | 3000 | 阅读拓展 | ✅ 是 |
| 三级字（姓氏/地名/科技术语） | 1605 | 查阅备用 | ⚠️ 入库但不列入学习阶段 |

**采集策略：8105 字全采**（POC 已验证可行），学习阶段覆盖一二级共 **6500 字**，三级字入库仅供查阅、不计入进度。这与"常用字到 7000"的目标基本一致，且来源权威、顺序可直接复用教育部分级。

### 1.2 ⚠️ 一处需要修正的现实：6000 字 / 3 年

你的设想是「小学段剩余 6000 字在 3 年内学完」。这需要摆一个数据：

| 依据 | 累计识字量 |
| --- | --- |
| 2022 版义务教育语文课标 · 第一学段（1–2 年级） | 认识约 **1600** 字 |
| 第二学段（3–4 年级） | 累计约 **2500** 字 |
| 第三学段（5–6 年级） | 累计约 **3000** 字 |
| 小学毕业（人教版实际要求） | 会写 2500 字左右，认识 3000 字左右 |

也就是说，**小学 6 年的官方识字目标是 3000 字**，6000 字已经接近成人常用字总量，通常要到初中毕业才自然达成。3 年学完 6000 字 = 每天新学 5.5 个字且全部保持，对绝大多数儿童不现实，强行推进会伤害学习兴趣。

**因此采用「双节奏」方案**：字库全部备齐，节奏由家长选，系统按掌握度自适应推进，学得快就自动加速，学得慢也不掉队。

| 节奏 | 覆盖 | 周期 | 说明 |
| --- | --- | --- | --- |
| **标准节奏**（默认） | 学前 1120 字 + 小学 3000 字 | ~8 年 | 对齐人教版课标，稳 |
| **加速节奏**（可选） | 再加拓展 3500 字 | +2~3 年 | 孩子学有余力时开启，家长在设置里切换 |

关键是：**系统不锁死年级，掌握度模型决定推进速度**。阶段只是内容分组的边界，不是时间枷锁。孩子两个阶段都 3 星，自动跳级；某阶段正确率持续偏低，自动降档加练。

## 二、汉字学习阶段划分

### 2.1 总览

```
S0  数学题目常用字       ~140 字   ← 你指定的第一阶段，先解决"读不懂题"
S1–S5 学前阶段（中班→大班） 5×200 = 1000 字
G1–G12 小学阶段（一年级上 → 六年级下） 12×250 = 3000 字
X1–X6 拓展阶段（选学）     6×583 ≈ 3500 字
────────────────────────────────────────
合计学习阶段 1120 + 3000 = 4120 字（含拓展共 7620 字）
```

**与你的目标对齐检查**

| 你的要求 | 满足方式 |
| --- | --- |
| 中班开始识字 | S0 起步，4 岁可用 |
| 2 年最低 300 字 | S0(140) + S1(200) = 340 字 ✅ 保底 |
| 2 年最高约 1000 字 | S0–S5 全完成 = 1120 字 ✅ 上限 |
| 常用字到 7000 | 字库 8105，学习阶段覆盖 7620 ✅ |
| 多个学习阶段 | 共 24 个阶段（1 + 5 + 12 + 6） |

### 2.2 S0：数学题目常用字（约 140 字）

**为什么单独设这一阶段**：4–5 岁孩子最大的障碍不是不会算，是**读不懂题目**。"一共有几个""还剩多少""比…多"这些字不认识，数学能力无法被评估。S0 先打通读题能力。

**选字原则**：全部来自人教版一年级数学课本与实际题目语料，按"出现频率 × 语义必要性"排序。

### 2.3 S1–S5：学前阶段（中班 → 大班，2 年）

| 阶段 | 字数 | 内容侧重 | 示例 |
| --- | --- | --- | --- |
| S1 | 200 | 身体 · 家人 · 吃喝 · 最常见动词 | 人 口 手 目 爸 妈 我 你 他 大 小 吃 喝 走 看 |
| S2 | 200 | 动物 · 自然 · 颜色 · 数字 | 牛 羊 马 鸟 鱼 花 草 木 日 月 水 火 山 石 红 白 |
| S3 | 200 | 家居 · 衣物 · 方位 · 时间 | 门 户 车 米 衣 巾 床 桌 上 下 中 天 年 月 早 午 |
| S4 | 200 | 动作 · 情绪 · 社交 · 学校 | 学 书 字 画 唱 笑 哭 爱 好 家 朋 友 老 师 同 |
| S5 | 200 | 生活场景 · 常见名词 · 高频虚词 | 市 店 医 生 车 站 果 菜 饭 的 了 在 和 就 都 |

**选字原则**（按优先级）：
1. 儿童口语已会说的词优先（听得懂 → 认得快）
2. 具象名词 > 抽象词；高频字 > 低频字
3. 笔画由少到多（S1 平均 6 画，S5 平均 9 画）
4. 构字能力强的字优先（学会"木"能带出"林、树、桥"）
5. 每阶段末尾留 20 字做"本阶段复习 + 儿歌/短句阅读"

**配套**：每阶段配 8–10 篇**控字小故事**（只使用该阶段及之前的字），实现"学完就能读"。

### 2.4 G1–G12：小学阶段（人教版对齐全 12 学期）

按 2022 版课标识字量分配，每学期一个阶段：

| 阶段 | 对应 | 新增字 | 累计 |
| --- | --- | --- | --- |
| G1 | 一上 | 250 | 250 |
| G2 | 一下 | 250 | 500 |
| G3 | 二上 | 250 | 750 |
| G4 | 二下 | 250 | 1000 |
| G5–G6 | 三上/下 | 250×2 | 1500 |
| G7–G8 | 四上/下 | 250×2 | 2000 |
| G9–G12 | 五上/下、六上/下 | 250×4 | 3000 |

选字依据：以《义务教育语文课程标准（2022 年版）》识字表 + 人教版各册"生字表"为主，用通用规范一级字表补齐差额。

### 2.5 X1–X6：拓展阶段（选学）

剩余约 3500 字（二级字为主）分 6 段，每段 ~583 字，标注"选学/自主阅读"。面向学有余力、希望尽早自主阅读章节书的孩子。默认关闭，家长开启后才进入任务池。

## 三、组词与例句的"控字规则"（重要）

组词和例句**不能随意使用未学过的字**，否则孩子会被生僻字卡住。规则：

```
词/句可用性 = max(其中每个字所处的阶段序号)
例：「太阳」= 太(S3) + 阳(S3) → 从 S3 起可用
    「熊猫」= 熊(S2) + 猫(S2) → 从 S2 起可用
    「一共」= 一(S0) + 共(S0) → 从 S0 起可用
```

- 每个组词/例句在入库时计算 `min_stage` 字段，练习引擎按孩子当前阶段过滤。
- 找不到"全已学字"的组词时（低阶段常见），允许 1 个超纲字并标注拼音。
- 故事同理：L1 故事只用 S0–S1 字，L2 用 S0–S3 字，依此类推。

这条规则直接决定了"学完就能读"能不能成立，是内容质量的关键。

## 四、英语学习梯度（10 级）

英语不按年级，按**认知难度 + 词频**分级，每级 ≈ 2–3 个月。

| 级别 | 主题 | 目标量 | 内容 |
| --- | --- | --- | --- |
| **E1** | 字母与首音 | 26 字母 + 26 词 | A–Z 大小写、发音、书写描红；每个字母配 1 个代表性单词（A-Apple, B-Bear…） |
| **E2** | 自然拼读 CVC | ~60 词 | cat / dog / pig 等辅音-元音-辅音结构；听音拼读、押韵词族（-at, -og, -ig） |
| **E3** | 视觉词 · 预备级 | ~40 词 | Dolch Pre-primer：the, to, and, you, it, is, my, big, red… |
| **E4** | 主题名词 L1 | ~90 词 | 动物、颜色、数字、食物四大主题（最贴近幼儿生活） |
| **E5** | 视觉词 · 一级 + 身体家庭 | ~110 词 | Dolch Primer + family / body 主题 |
| **E6** | 动作词 + 视觉词 · 二级 | ~100 词 | 常用动词（go/see/play）+ Dolch Grade 1 |
| **E7** | 主题名词 L2 | ~120 词 | 学校、家居、衣物、天气、交通 |
| **E8** | 描述词 + 视觉词 · 三级 | ~110 词 | 形容词反义词对（big/small, hot/cold）+ Dolch Grade 2 |
| **E9** | 主题名词 L3 + 时间 | ~120 词 | 自然、时间、星期月份、地点 |
| **E10** | 句型与短文 | ~130 句型 + 60 篇短文 | What's this? / I like… / How many…? 分级短文阅读 |

**累计**：约 **900 个单词 + 130 个句型**，覆盖 Dolch 220 视觉词全部 + Fry 前 300 高频词 + 16 大主题名词。

**每个单词的字段**：拼写、音标（ECDICT）、中文释义、例句（英+中）、配图（CC0 图库）、发音音频（TTS 生成）、词频、所属主题、所属级别。

**为什么这样分**：先解决"英语耳朵和嘴巴"（E1–E3 听说为主，不要求拼写），再解决"认读"（E4 起图文卡），最后才要求书写与句型（E10）。符合幼儿二语习得的沉默期规律。

## 五、视频方案（B 站外链 + 本地上传）

### 5.1 两种来源

| 来源 | 实现 | 说明 |
| --- | --- | --- |
| **B 站外链** | 家长贴 `BV号` 或完整链接 → 服务端正则提取 BV 号 → 存储 + 用 `player.bilibili.com/player.html?bvid=xxx&high_quality=1` 内嵌播放 | 不下载、不转码、不占存储；仅存元数据（标题、时长、封面、分级、字幕） |
| **本地上传** | 家长上传 MP4 → 服务端存对象存储 → HLS 切片或直接 HTTP Range 播放 | 支持自家录的、下载的合规内容；需限制单文件大小（建议 ≤ 500MB） |

### 5.2 关键约束

- **白名单制**：孩子端只能播放家长添加过的视频，无搜索、无推荐、无跳转外站，规避内容风险。
- **观看控制**：家长设置每日视频时长上限（默认 15 分钟）、可观看时段；到时自动停止并提示休息。
- **字幕**：支持外挂 SRT/VTT 字幕，可切换"中/英/双语/关闭"。
- **观看记录**：记录观看时长与完成度，计入每日总时长（与练习时长共用额度）。
- **免责**：家长自行添加的第三方链接，系统不做内容审核，需家长自负责任（首次添加时弹确认）。

## 六、TTS 语音合成方案

汉字读音、单词发音、故事朗读都需要音频。推荐方案：

| 方案 | 优点 | 缺点 | 建议 |
| --- | --- | --- | --- |
| **piper（离线 ONNX TTS）** | 完全离线、零成本、可批量预生成、无隐私外传 | 音质一般（机械感）、需部署模型 | ✅ 中文首选（zh_CN-huayan-medium 等） |
| **Edge TTS 接口** | 音质自然、多发音人、免费 | 非官方接口，有失效风险，需联网 | ✅ 用于生成高品质音频后缓存入库 |
| 云厂商 TTS（Azure/阿里/腾讯） | 稳定、音质好、有 SLA | 要钱、要联网、儿童语音数据外传 | 备选 |
| eSpeak-ng | 极轻量、纯离线 | 音质差 | 仅作兜底 |

**实施建议**：
1. 服务端做一层 `TTSProvider` 接口抽象，piper / EdgeTTS 双实现，可切换。
2. **批量预生成**：部署后由 worker 一次性把 8105 个汉字读音 + 900 个单词发音 + 故事朗读全部生成，存对象存储。避免运行时请求外部服务。
3. 多音字处理：汉字读音按**词语语境**生成（如"长"在"长短"里 cháng，在"长大"里 zhǎng），所以音频以"词/例句"为单位生成，而非单字。
4. 英语单词发音用 piper `en_GB-alba-medium` 或 `en_US-lessac-medium`。

## 七、部署与服务器（"先能跑再说"）

**起步配置**：2 核 4G + 60GB SSD（约 ¥100/月档），单台跑全部服务。

```
Caddy（自动 HTTPS + 反向代理）
  ├── Go API（:8080）
  ├── Go Worker（爬虫 / 日报 / TTS 预生成 / PDF）
  └── PostgreSQL 16（同机，每日 pg_dump 备份保留 30 天）
对象存储：本地卷 ./var/storage（后期可切 MinIO / COS）
```

**理由**：家庭场景并发 < 10，2C4G 绰绰有余；单一 Docker Compose 一把梭，`git pull && docker compose up -d` 即可升级。数据量预估：8105 汉字 ≈ 20MB、笔顺数据 ≈ 40MB、音频 ≈ 2–5GB（TTS 预生成后）、PostgreSQL ≈ 500MB（含一年答题流水）。60GB 够用，音频增长后按需扩盘。

## 八、采集优先级（"先采集再开发"）

按你的要求，开发前先跑采集验证。执行顺序：

| 批次 | 内容 | 数据源 | 预期规模 |
| --- | --- | --- | --- |
| P1 | 汉字：拼音 / 部首 / 笔画 / 笔顺 | 通用规范汉字表 + 新华字典 + hanzi-writer | **实测 8103 字**（拼音 100% / 笔画 91.5% / 笔顺 84.7% / 部首 83.3%）✅ 已完成 |
| P2 | 组词 | ~~THUOCL 领域词库~~ → **生成 + 控字校验**（实测领域词库给出"丁酸、丙二醇、灌丛"，不可用） | ~2 万条 |
| P3 | 英语单词：音标 / 释义 / 词频 | ECDICT 开源英汉词典 | 命中 400+，高频池 1500 |
| P4 | 配图 | Openverse / Wikimedia Commons（CC0） | 按需 |
| P5 | TTS 音频 | piper / EdgeTTS 批量生成 | 9000+ 条 |
| P6 | 分级故事 | **原创生成 + 控字校验**（不爬取） | 80–100 篇 |
| P7 | 视频 | 家长手动添加（不采集） | — |

**P6 为什么不爬**：中文儿童读物的现成文本几乎全部在版权保护期内，爬取风险高、质量不可控。改为按字表**原创生成 + 自动控字校验**（校验脚本检查每个字是否属于目标阶段，超纲字自动标注或替换），质量与合规性都更好，且能精确匹配我们自己定义的 S0–S5 字表——这是任何现成读物都做不到的。

> 实测细节见《采集可行性报告》。其中组词一项的 POC 结论是**否定性的**：开源的领域词库（THUOCL）给出的高频词是"一审、丁酸、丙二醇、灌丛"这类专业术语，对幼儿无意义。这条如果不提前发现，会直接影响识字卡的可用性。

## 十、阶段推进的自适应规则

阶段只定义内容边界，实际推进由掌握度驱动：

| 条件 | 系统行为 |
| --- | --- |
| 当前阶段内 ≥90% 知识点达到 level ≥4 | 自动解锁下一阶段，通知家长 |
| 连续 3 天正确率 <60% | 暂停新学，转入复习 + 建议打印专项练习 |
| 复习积压 >100 条 | 强制复习日，不派发新内容 |
| 家长手动跳级 | 允许，但需确认（避免拔苗助长） |
| 家长锁定难度 | 关闭自动跳级，固定在当前阶段 |

新学速率默认 **每天 5 个新知识点**（家长可调 3–10），复习量由间隔重复算法决定，两者之和为当日任务量。
