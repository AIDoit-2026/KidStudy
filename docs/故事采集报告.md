## 四、适宜性筛查

分两级，避免一刀切：

| 级别 | 词库内容 | 数量 | 处理 |
| --- | --- | --- | --- |
| **拦截**（unsafe） | 血腥暴力（杀死/尸体/鲜血/屠杀）、成人（情夫/通奸/嫖/色情）、粗口（混蛋/杂种/他妈）、毒品赌博 | **2,450 篇** | 阅读器默认屏蔽，家长可手动解除 |
| **存疑**（caution） | 童话里常见的鬼怪、悼念场景、寓言里的负面行为（偷/骗/报仇/打仗） | 5,686 篇 | 正常展示，家长后台可单独过滤 |
| **可用** | 无上述两类 | **9,714 篇** | 直接纳入 |

**为什么分两级**：第一版把「鬼 / 坟 / 傻子 / 王八」都放进拦截库，误杀率 **19%**（3,263 篇）。抽查发现大量正常篇目被误伤——《妈妈赶走了"鬼"》《乌龟给老鹰的教训》（"王八"是乌龟俗称）《布娃娃和小女孩》（温情故事里提到坟）。这类词放进「家长确认」级更合适，家长可以按自家接受度决定。

## 五、⚠️ 最重要的发现：分级结果偏难

用《内容与分级体系设计》的 24 阶段字表做**控字校验**，按「98% 用字覆盖」算最低可读阶段：

| 阶段 | 可用篇数 | 累计 |
| --- | --- | --- |
| S5 | 1 | 1 |
| G1（一上） | 12 | 13 |
| G2（一下） | 48 | 61 |
| G3（二上） | 176 | 237 |
| G4（二下） | 421 | 658 |
| G5（三上） | 794 | 1452 |
| G6（三下） | 1314 | 2766 |
| G7–G12 | 5430 | 8196 |
| X1–X6（拓展） | 272 | 9468 |

**关键数字**：
- 累计到 G6（小学毕业水平）可读：**2,766 篇**
- 累计到 G3（二年级）：**237 篇**
- **S0–S5（学前阶段）几乎为零 —— 只有 1 篇**

### 这意味着什么

**这 17,250 篇不能给孩子自主阅读，尤其是 4–6 岁的学龄前阶段完全指望不上。**

原因不是采集失败，而是源站的定位：它们是成人/通用向的故事集（普遍 500–2500 字的完整叙事），从来不是按字表控字编写的儿童分级读物。任何一篇 800 字的正常文章，用字几乎必然溢出 S5 的 1155 字。

### 那怎么用它

三条务实路径，按推荐度排序：

1. **亲子共读 / 家长朗读**（最推荐，立即可用）
   家长读、孩子听。按 <400 字短篇筛选有 **3,280 篇**，其中 ≤G6 难度的 1,273 篇。这个组合对 5–8 岁很合适。

2. **TTS 音频**（自动化版本）
   接本地 TTS（piper / EdgeTTS）把 3,280 篇短篇合成为音频，做成「睡前故事电台」。这正好复用之前定的音频方案，孩子完全不用看屏幕。

3. **改写/缩写到 S0–S5**（工作量最大）
   用控字改写成 500–1500 字的精简版本。只有这条路能真正喂给正在学 S3 的孩子自主阅读，但需要额外的内容管线。

**我的建议**：先用第 1、2 条把 17,250 篇盘活（零额外内容成本），第 3 条作为后续 M 阶段的可选项。

## 六、过程中修掉的两个真实缺陷

### 6.1 阶段字表存在 568 个跨阶段重复字

校验时发现 `stages.json` 累加 8,103 字，去重后只有 7,535 字，**148 个字同时属于多个阶段**（如「国」「这」「为」「以」「要」同时出现在 S1–S5）。

根因在 `build_stages.py`：当多个 S 阶段的种子词都不足 200 字、需要从通用字表补齐时，代码每次都从 `rest[0:]` 起点切，导致重复。

```python
# 修复前：base 每次都从 rest 头部取，i 只在分支内累加
base = seeded.get(f"S{k}", [])[:200]
if len(base) < 200:
    base = base + rest[:200 - len(base)]
    i += 200 - len(seeded.get(f"S{k}", [])[:200])

# 修复后：始终从 rest[i:] 切，严格递增
need = 200 - len(base)
if need > 0:
    base += rest[i:i + need]
    i += need
```

修复后 **8,103 字零重复**，并加了运行时断言防止同类问题再次静默发生。

这个缺陷会**人为抬高所有含冲突字的文章分级**（"国"被算作 S5 的字），修完后 S5 起点就出现了可读篇目。

### 6.2 分级判据从 100% 改为 98% 覆盖

初版要求正文中**每一个字**都在目标阶段内，只要出现 1 个人名生僻字，整篇就被推到 X 阶段。改为「98% 用字覆盖」后分布合理多了（最低门槛从 G2 降到 S5）。

## 七、复跑与增量

```bash
# 全量（幂等：已落盘的文件自动跳过）
python tools/crawl_stories.py --workers 10

# 只重建 URL 清单（站点更新后用）
python tools/crawl_stories.py --list-only

# 用已有清单只抓正文
python tools/crawl_stories.py --detail-only

# 补采失败项
python tools/crawl_stories.py --retry-failed

# 只看统计
python tools/crawl_stories.py --stats

# 重新分析分级（改了词库或字表后必跑）
python tools/analyze_stories.py
```
