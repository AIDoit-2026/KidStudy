# KidStudy · B 站视频资源清单

> 说明：B 站的搜索接口有反爬风控（`api.bilibili.com` 直接返回 HTML），**这里不抓取、不下载视频**。
> 本清单只整理**可在 B 站打开的搜索直达地址**，家长打开后挑合适的片子，把链接或 BV 号填进应用即可。
> 应用内的处理：家长粘贴链接 → 服务端正则提取 BV 号 → 用官方播放器 `player.bilibili.com/player.html?bvid=xxx` 内嵌播放。**零下载、零转码、零存储**。

**格式：标题 | 地址 | BV号（家长填写）**

---

## 一、家长如何拿到地址

1. 点下面的搜索链接 → 在 B 站挑一个画质好、时长合适的视频
2. 复制浏览器地址栏，形如 `https://www.bilibili.com/video/BV1xx411c7mD`
3. 在应用的「视频管理 → 添加外链」里粘贴，系统自动提取 `BV1xx411c7mD`
4. 填好：标题、适合级别（E1–E10）、时长、是否带中文字幕 → 保存
5. 孩子端只显示家长添加过的视频，**无搜索、无推荐、无跳转外站**

## 七、给家长的使用建议

- **控制时长**：建议每天视频 ≤15 分钟，且必须陪看——和"练习"时长共用每日额度。
- **优先慢速资源**：`Super Simple Songs`、`Alphablocks` 语速慢、画面干净，适合 E1–E3；`Peppa Pig` 语速偏快，建议 E6 以后。
- **字幕开关**：初期开中文字幕，E5 以后切英文字幕，E8 以后尝试无字幕。
- **别用"推荐流"**：不要让孩子在 B 站 App 里自由浏览，只在我们的应用里看已添加的白名单视频。

## 八、后续：要不要我直接扒 BV 号？

可以，但需要你先决定：

1. **手动填**（推荐）：家长自己在 B 站挑，质量最可控，也就填 30–50 条的事。
2. **我写带登录 Cookie 的采集器**：需要你在浏览器登录 B 站后把 Cookie 给我（`SESSDATA`），我按关键词批量取前 N 个视频的标题+BV 号写进这个文档。**账号安全风险自负**。
3. **换成官方 API**：B 站开放平台需要申请 key，周期长，家庭自用途中必要性不大。
