**问题**：THUOCL 是清华的**领域词库**（IT / 医学 / 法律 / 财经 / 动物 / 食物 / 成语 / 诗歌 / 地名 / 汽车），它高频出现的词是"一审、丁酸、丙二醇、灌丛"这类**专业术语和地名**，对 4–8 岁孩子毫无意义，甚至有歧义。

**这是本次 POC 最有价值的发现**——如果直接拿它当组词库，做出来的识字卡会很难用。

数据源：**结巴主词典 `dict.txt.big`**（58 万词，通用语料词频，MIT）。过滤后得 24.5 万条 2–3 字词。

**清洗规则（三轮迭代踩坑总结）**

| 问题 | 处理 |
| --- | --- |
| 繁体异体混入（一個、韋小寶、天安門） | 只保留全部字都在《通用规范汉字表》内的词 |
| **军事政治词**（敌人、敌军、抗日、战场、县委） | 敏感词黑名单 + 敏感字兜底（尸/屎/屁/淫/赌/毒/匪/奸/屠/妓） |
| **粗口脏话**（妈→他妈的、狗→狗日/走狗、奶→二奶、猪→母猪） | 同上黑名单，**这条是儿童应用的红线，必须在入库前拦截** |
| 专有名词（武汉、石首、房县、市长） | 部分缓解；残留较多的是书面词（超导、现场、业主） |
| 控字过严导致常用字无词（家/子/门/口/生） | 全控字词 <4 个时，放宽到"允许 1 个超纲字"并标记 `words_with_new_char` |

**产出**：`var/raw/stages.json`（24 阶段字表）、`var/raw/stage_words.jsonl`（每字 6 个控字组词）、`var/raw/stage_report.md`

### 2.4 副产物：纠正了阶段字表的排序方法

按「字常用度」自动排序时，S1 出来的是 **国、人、生、地、这、发、行** —— 这是**新闻语料的字频，不是幼儿口语字频**。

改为：**S0 与 S1–S5 用人工主题种子词**提取（`tools/curated_seeds.json`，每阶段约 100 个儿童生活主题词），G/X 阶段才用自动字频。修正后：

| 阶段 | 修正前 | 修正后 |
| --- | --- | --- |
| S1 | 国人生活这子发学 | **爸 妈 爷 奶 哥** |
| S2 | 河技使阳信农取历 | **猫 狗 猪 羊 马** |
| S3 | 药严该宝素切兴父 | **房 窗 户 桌 椅** |
| S4 | 敌威座著限介春福 | **学 校 师 生 课** |

### 2.5 残留问题（诚实交代）

即使换源 + 三重过滤，低阶段仍有少量不合适词：`妈→干妈/后妈`、`狗→狗头`、`猪→猪头`、`奶→奶子`、`市→市长/武汉`。

**结论：自动生成只能作为候选池。** S0–S5 这 1120 字（孩子最关键的起步阶段）建议：

1. 由 `curated_seeds.json` 的主题词直接派生组词，而非从全量词库捞；
2. 或保留自动池 + 家长在审核后台做一次勾选。
3. **必须在 `content_review` 流程里过一遍人眼**，不要直接上线。

### 2.6 组词方案（最终）

| 方案 | 做法 | 评价 |
| --- | --- | --- |
| ❌ 领域词库直取 | THUOCL Top8 | 已证明不可用 |
| ⚠️ 换通用词频表 | 拼音输入法词库 / rime 词库 | 质量好但**多为商业词库，有版权风险**；开源通用词表质量参差 |
| ✅ **生成 + 控字校验（推荐）** | 对每个字生成 4–6 个**儿童生活场景**组词，自动校验"用字是否属于已学阶段"，超纲字自动替换或标注拼音 | 质量最高、天然符合分级、无版权风险 |
| ✅ 家长词表导入 | 学校发的生字表 / 家长自定义 CSV | 兜底与个性化通道 |

**推荐组合**：生成（主力，覆盖 S0–S5 与 G1–G12 共 4120 字）+ THUOCL 仅作**词频校验与去重**（判断生成的词是否真实常用）+ 家长导入兜底。

组词生成量估算：4120 字 × 5 词 = **约 2 万条**，配合自动控字校验脚本，可控。

### 3.1 踩到的坑：ECDICT 的 `frq` 是排名不是频次

`frq` 数值**越小越常用**（cat=1775，jadeite=47047）。第一版脚本按降序取，捞出来的"高频词"全是 tonus、proline、jadeite、ranula 这类医学化学词——**与汉字组词那次同类错误，方向搞反**。已修正为升序。

### 3.2 第二个坑：纯按词频切 N 个词不适合幼儿

高频池第 300 名附近就已经出现 `explain`、`develop`、`view`、`carry`、`price`。这验证了设计上的选择：**不能按词频切前 900 个当幼儿词表**。正确做法是——

1. **内容词**（名词/动词/形容词）用人工核定的 16 大主题种子词圈定语义范围（动物、食物、身体、家庭…），确保都是"幼儿生活世界"里的东西；
2. **功能词**（the / of / you / my / can）才从词频榜取；
3. 分级顺序参考 `frq` + `collins` 星级 + `oxford` 标记 + 词长。

### 3.3 需要清洗：中文释义带词典噪音

`translation` 字段是多词性全量释义，含大量计算机/医学/化学义项，例如：

- `cat` → "n. 猫, 恶妇\nvi. 呕吐\n计算机辅助教育, 计算机辅助测试…"
- `a` → "art.\n[计] 累加器, 加法器, 地…"

**入库前必须清洗**：只取第一个词性的第一个义项，并剔除 `[计]` `[医]` `[化]` `[法]` 等专业义项。这条要写进正式采集器的清洗规则。

## 四、中文小故事：不采集，改为原创生成

| 候选来源 | 问题 |
| --- | --- |
| 儿童读物网站、绘本 PDF、故事 APP | 几乎全部在版权保护期内，爬取 = 侵权 |
| 中文维基文库 | 多为古籍文言，不适合幼儿；白话译本版权状态复杂 |
| 《伊索寓言》《格林童话》早期译本 | 公有领域可用，但语感老旧、用字不受控，与我们的 S0–S5 字表对不上 |

**决定：原创生成 + 控字校验**。这不只是退而求其次，而是**唯一能满足"控字"要求的做法**——分级故事的核心价值是"孩子学完 S2 的字，就能读懂 L2 的故事"，任何现成读物都无法精确匹配我们自定义的字表。

生成规格：
- 每篇 150–400 字，按目标阶段只使用该阶段及之前的字（超纲字 ≤2% 且自动注音）
- 每篇配 2–3 道阅读理解题 + 1 道家长口头讨论题
- 目标 **L1–L12 共 120 篇**（每个汉字阶段 5 篇左右）+ 英语分级短文 60 篇
- 全部入库前跑控字校验脚本，不达标自动重写

## 七、环境备注：国外数据源走代理

GitHub raw / npm registry 在国内直连极慢（实测约 25 KB/s，且会中途断连）。设置代理后约 74 KB/s 且稳定：

```bash
set https_proxy=http://127.0.0.1:11086
set http_proxy=http://127.0.0.1:11086
curl -x http://127.0.0.1:11086 -o ecdict.csv <url>     # curl 用 -x
```

脚本内 `urllib` 会自动读取这两个环境变量，无需改代码。66 MB 的 ECDICT 走代理约 3 分钟下完。
