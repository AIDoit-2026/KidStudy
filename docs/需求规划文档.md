## 一、项目定位与一句话定义

> 一个面向家庭场景的幼儿启蒙学习平台：由家长主导、孩子使用，覆盖**语文 / 数学 / 英语**三科，内置**护眼自适应界面**、**纸质打印输出**、**学习评价与进度追踪**，让家长既能用屏幕教，也能随时把学习内容变成纸上练习。

### 1.1 与市面产品的差异点

| 差异点 | 说明 |
| --- | --- |
| 家长主导，而非孩子自助 | 产品第一用户是**家长**。家长排任务、看报表、控时长；孩子界面极简、无广告、无社交。 |
| 屏幕不是唯一载体 | 任何学习内容都可一键生成**A4 可打印练习卷**（描红、口算、单词卡、找规律），这是核心能力而非附加功能。 |
| 护眼是一等需求 | 护眼不是"加个夜间模式"，而是贯穿配色、字号、动效、时长控制、休息提醒的系统性设计。 |
| 内容可生长 | 服务端带**爬虫采集子系统**，可持续补充汉字、单词、故事、视频素材，家长审核后上线。 |

### 1.2 明确不做的（避免范围膨胀）

- 不做孩子自主注册、社交、排行榜（涉及儿童隐私与沉迷风险）
- 不做直播课 / 真人教师 / 即时答疑
- 不做 APP 应用商店发布（首期以响应式 Web + PWA 为主）
- 不做付费订阅与支付（首期单机家庭使用）

## 二、用户角色与使用场景

### 2.1 角色定义

| 角色 | 谁 | 主要诉求 | 入口 |
| --- | --- | --- | --- |
| 家长（Parent） | 孩子的父母 | 安排学习内容、控制时长、看学习报告、审核内容、打印材料 | 桌面浏览器 / 手机 |
| 孩子（Child） | 4–8 岁儿童 | 完成今日任务，看星星和成长反馈 | 平板 / 大屏 / 手机（由家长登录后切换） |
| 管理员（Admin） | 部署者本人 | 管理爬虫源、数据源、系统配置 | 后台 |

### 2.2 典型场景

**场景 A — 晚上 20 分钟亲子学习（大屏为主）**
1. 家长在客厅大屏/平板打开应用，首页显示二维码。
2. 手机扫码登录家长账号（已登录状态的手机确认即可）。
3. 选择"宝宝 A"，系统根据掌握度模型给出今日任务：复习 8 个汉字 + 新学 6 个汉字 + 20 道 10 以内加减法 + 5 个英语单词。
4. 孩子逐个完成，答对有星星反馈，答错进入错题本。
5. 20 分钟后系统提示"该休息啦"，锁屏并展示今日战绩。

**场景 B — 周末纸质练习（打印）**
1. 家长在"打印中心"选择：语文描红（本周学的 20 个汉字）、数学口算 60 题、英语看图单词连线。
2. 选择"孩子版（无答案）/ 家长版（含答案）"、A4、每页题量。
3. 前端直接调起打印或导出 PDF 存档。
4. 孩子纸上完成后，家长可在应用中"标记本次纸质练习完成"，计入进度。

**场景 C — 家长复盘（手机）**
1. 家长手机打开报表：本周学习 5 天、累计 92 分钟；语文掌握汉字 137 个，数学 20 以内加减法正确率 78%（薄弱：退位减法）；英语单词 45 个。
2. 系统给出建议："退位减法连续 3 天正确率低于 60%，建议降低难度并打印专项练习 20 题"。
3. 家长一键生成专项练习并加入下周任务。

## 三、功能需求

### 3.1 学科与内容体系

#### 3.1.1 语文

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 识字 | 汉字卡 | 按新课标一年级识字表分级（约 300 字起步，逐步扩展到 1000+）。每个字含：读音（拼音+音频）、部首、笔画数、笔顺动画、组词 2–4 个、例句 1–2 句、配图。 |
| 拼音 | 声母 / 韵母 / 整体认读 / 四声 | 卡片 + 听音选拼音 + 拼读练习。 |
| 词语 | 组词、近反义词、量词 | 与识字联动，学过的字优先组词。 |
| 分级阅读 | 中文小故事 | 按识字量分级（L1 用字 ≤ 100，L2 ≤ 300，L3 ≤ 500）。每篇含：正文、生字标注、朗读音频、2–3 道阅读理解题、思考讨论题（供家长口头提问）。 |
| 古诗启蒙 | 简短古诗 | 五言绝句为主，配译文、朗读、填空背诵。 |

**汉字学习交互**：看字 → 听读音 → 笔顺动画（可手写描摹） → 组词 → 选词填空 → 进入复习队列。

#### 3.1.2 数学

| 模块 | 题型 | 难度阶梯 |
| --- | --- | --- |
| 数与运算 | 加法、减法、加减混合、连加连减、竖式 | 10 以内 → 20 以内（含进位/退位） → 100 以内 → 两位数加减 |
| 比较 | 比大小（>、<、=）、比多少、最长/最短、最高/最矮 | 图形比较 → 数字比较 → 算式比较 |
| 找规律 | 数字规律、图形规律、颜色规律、递增递减 | 2 项循环 → 3 项循环 → 等差递增 → 复合规律 |
| 数数与认数 | 数数、数的分解与组成、数轴填空 | 1–10 → 1–20 → 1–100 |
| 认识图形 | 平面图形、立体图形、图形计数 | 静态识别 → 分类 → 计数 |
| 生活应用 | 认识钟表、认识人民币、简单应用题 | 情景化，含实物配图 |

**关键设计：数学题采用「模板 + 参数化生成」**，服务端保存题型模板（`math_templates`），运行时按难度参数随机生成题目，**题库无限且可控**，不需要人工录入每一道题。生成时带确定性随机种子（seed），保证同一份练习卷可复现。

#### 3.1.3 英语

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 字母 | 26 个字母大小写 + 发音 + 书写 | 含描红打印。 |
| 自然拼读 | Phonics：CVC 单词、字母组合发音 | 听音辨字母、拼读合成。 |
| 高频词 | Dolch / Fry sight words 分级 | 220 个 Dolch 词，按年级分 5 级。 |
| 主题单词 | 动物、食物、颜色、家庭、身体、天气等 | 每个单词含：拼写、音标、中文释义、例句、配图、发音音频。 |
| 动画视频 | 英文启蒙动画片段 | **外链或本地文件**，配英文字幕开关、可设置每集时长。 |
| 简单句型 | Hello / What's this / I like... | 跟读 + 选择题。 |

**视频模块（已定方案）**：
- **B 站外链，不下载**：家长粘贴链接或 BV 号 → 服务端提取 BV 号 → 用官方播放器 `player.bilibili.com/player.html?bvid=xxx` 内嵌播放，服务端只存元数据（标题、时长、封面、分级、字幕）。零下载、零转码、零存储成本。
- **本地上传**：支持家长上传 MP4 存对象存储，单文件 ≤500MB。
- **白名单制**：孩子端只能播放家长添加过的视频，无搜索、无推荐、无外站跳转。
- **观看控制**：每日视频时长上限（默认 15 分钟）+ 可观看时段，到时自动停止并提示休息；观看时长计入每日总时长额度。
- **字幕**：支持外挂 SRT/VTT，可切换中/英/双语/关闭。

### 3.2 练习引擎与学习流程

统一的「任务卡（Task Card）」模型，三科共用一套练习运行时：

```
今日任务 = 复习队列（间隔重复到期） + 新学内容（按日上限） + 家长指定专项
```

| 题型（通用） | 说明 |
| --- | --- |
| `choice_text` | 四选一（文字） |
| `choice_image` | 四选一（图片） |
| `choice_audio` | 听音选择 |
| `fill_blank` | 填空（打字或选字块） |
| `match` | 连线配对 |
| `order` | 排序（组词成句、排数字顺序） |
| `trace` | 描红 / 手写（触屏或鼠标） |
| `true_false` | 判断对错 |
| `oral` | 跟读（家长评分或跳过，不计入自动评分） |

**答题反馈规则**
- 答对：即时正向反馈（动画 + 音效 + 星星），2 秒后可继续。
- 答错：不惩罚、不红叉（避免挫败），显示正确答案 + 一句解释，该题进入错题本。
- 连对 3 题：额外奖励星。
- 每题可「跳过」，跳过的题不计正确率但计入完成度。

### 3.3 评价机制

#### 3.3.1 掌握度模型（间隔重复，简化 SM-2）

每个「孩子 × 知识点」维护一条 `mastery_record`：

| 字段 | 含义 |
| --- | --- |
| `level` | 掌握等级 0–5（0 未学，5 已掌握） |
| `ease` | 难度因子，初始 2.5 |
| `interval_hours` | 下次复习间隔 |
| `next_review_at` | 下次复习时间 |
| `correct_count` / `wrong_count` / `streak` | 统计 |

**升级规则**：连续答对 → 间隔 ×1.8（1h → 4h → 1天 → 3天 → 7天 → 15天 → 毕业）；答错 → 回到 level-1，间隔重置为 10 分钟并在本次会话内复现一次。

**知识点粒度**：
- 语文：单个汉字 / 单个词语 / 单篇故事
- 数学：题型 × 难度档（如"20以内退位减法"）
- 英语：单个单词 / 单个句型

#### 3.3.2 星级与成就

| 评价项 | 规则 |
| --- | --- |
| 单次任务星级 | 正确率 ≥90% 且无提示 = 3 星；≥75% = 2 星；≥60% = 1 星；<60% 不给星但给"再试一次"鼓励 |
| 提示扣分 | 使用提示最多扣 1 星 |
| 每日目标 | 完成今日任务 = 点亮当日徽章 |
| 连续学习 | streak 天数：3/7/15/30/100 天对应成就 |
| 里程碑 | 累计识字 100/300/500 字、单词 50/150/300 个、口算 500/2000 题 |
| 学科树 | 可视化"成长树"，每掌握 10 个知识点长一片叶子（正向、非竞争性） |

**原则**：评价只做正向激励，**不出现排名、不出现负向标签、不出现"落后"类文案**。

#### 3.3.3 错题本

- 自动收集答错与跳过的题，次日进入复习队列首位。
- 连续答对 3 次后移出错题本。
- 支持家长一键"错题专项打印"。

### 3.4 学习进度记录

| 记录层 | 表 | 用途 |
| --- | --- | --- |
| 原始流水 | `answer_logs` | 每次作答：题 ID、对错、用时、是否提示、时间戳（按月分区） |
| 会话层 | `learning_sessions` | 一次学习：孩子、开始/结束、时长、设备、完成题量、获星数 |
| 日汇总 | `daily_stats` | 每孩子每日：各科时长、题量、正确率、新掌握知识点数（异步汇总，报表直读） |
| 掌握度 | `mastery_records` | 见 3.3.1 |

**家长报表内容**

1. **今日概览**：学习时长、完成任务数、星星数、是否触发休息提醒。
2. **趋势图**：近 30 天学习时长 / 正确率折线（Recharts）。
3. **学科详情**：
   - 语文：累计识字量、本周新增、待复习量、故事阅读篇数
   - 数学：各题型正确率热力图、薄弱题型 Top5
   - 英语：掌握单词数、动画观看时长、跟读次数
4. **智能建议**（规则引擎，非 AI 黑盒）：
   - 某知识点连续 3 天正确率 <60% → 建议降档 + 生成专项练习
   - 某科连续 5 天未学习 → 提醒均衡
   - 复习积压 >100 条 → 建议调整为复习日，暂停新学
5. **导出**：报表导出 CSV / PDF，可打印贴在墙上。

### 3.5 打印功能（核心差异化能力）

#### 3.5.1 打印模板

| 模板 | 内容 | 说明 |
| --- | --- | --- |
| 汉字描红卡 | 田字格 + 灰底描红 + 笔顺示意 + 拼音 | 每页 8–12 字，可选"带拼音/不带拼音"、"描红/空格临写" |
| 汉字闪卡 | 大字正面 + 拼音组词背面 | 支持双面打印（奇数页正面、偶数页背面） |
| 拼音练习 | 四线三格书写 + 声母韵母表 | |
| 口算题卡 | N 道加减法，竖排分栏 | 每页 40/60/100 题可选，可指定难度与题型混合 |
| 比大小 / 找规律 | 图形题 | 图形用 SVG 保证打印清晰 |
| 英语单词卡 | 图 + 单词 + 中文 | 双面打印 |
| 字母描红 | 四线三格 26 字母 | |
| 连线题 | 单词-图片、算式-结果 | |
| 故事小册子 | 分级故事 + 生字表 + 思考题 | A5 小册子排版，可折叠装订 |
| 周学习报告 | 家长版 | 图表 + 建议 |

#### 3.5.2 打印实现方案

```
前端打印预览路由 /print/:templateId?params=...
  ├── 纯 CSS @media print（推荐主路径，零依赖、所见即所得）
  │     - 隐藏导航/按钮/动画
  │     - 白底黑字、高对比
  │     - @page { size: A4; margin: 15mm }
  │     - break-inside: avoid 防止题目被截断
  └── 服务端 PDF 导出（Go + chromedp 无头浏览器）
        - 用于"存档/批量下载/邮件发送"
        - 同一套 HTML 模板，保证与浏览器打印一致
```

**关键细节**
- 打印参数：纸张（A4/A5）、方向、每页题量、字号（大中小，照顾低龄）、是否含答案、份数、日期水印。
- **答案页分离**：默认生成"孩子版"，家长可单独打印答案页。
- 打印记录：记录 `print_jobs`（谁、何时、什么模板、参数），避免重复打印同一套题；打印的内容可标记为"纸质完成"补录进度。
- 字体：中文优先使用开源楷体/手写体（如霞鹜文楷 LXGW WenKai，OFL 协议），描红效果远好于黑体。

### 3.6 护眼与多端自适应

#### 3.6.1 护眼设计（硬需求）

| 措施 | 实现 |
| --- | --- |
| 低蓝光配色 | 默认"纸感米黄"主题（背景 `#F5F1E8`、正文 `#3A3226`），避免纯白 `#FFF` + 纯黑 `#000` 的高对比刺激 |
| 深色模式 | 日落自动切换（按经纬度/时区或家长设定时间）+ 手动切换 + 跟随系统 `prefers-color-scheme` |
| 亮度/对比度 | 提供亮度蒙层（0–30% 变暗）、对比度档位，存本地 |
| 字号与间距 | 三档字号（小/标准/大字），行高 ≥1.8，字间距可调；低龄默认大字 |
| 动效克制 | 禁止闪烁、禁止高频动画；反馈动画 ≤300ms 且可关闭；尊重 `prefers-reduced-motion` |
| 20-20-20 提醒 | 每 20 分钟弹全屏休息页，引导看远处 20 秒，倒计时结束才可继续（时长可配 15/20/30） |
| 单次时长上限 | 家长设置（默认 20 分钟/次、60 分钟/天），到时锁屏，需家长 PIN 解锁 |
| 观看距离提示 | 大屏模式下提示"请保持 2 米以上观看距离" |
| 内容密度 | 单屏题目数：手机 1 题、平板 2 题、大屏 2–3 题，绝不堆砌 |

#### 3.6.2 响应式断点

| 断点 | 设备 | 布局 |
| --- | --- | --- |
| `< 640px` | 手机竖屏 | 单列，底部大按钮，热区 ≥ 56px |
| `640–1024px` | 平板竖屏 / 手机横屏 | 单列加宽，卡片居中 |
| `1024–1600px` | 平板横屏 / 桌面 | 双列，左侧内容右侧反馈 |
| `> 1600px` | 电视 / 客厅大屏 | 最大内容宽度 1400px 居中，字号 +20%，遥控器/方向键可操作，热区 ≥ 64px |

**大屏补充**：支持键盘方向键 + 回车操作；提供"投屏模式"（隐藏家长入口，防孩子误操作）。

### 3.7 账号、权限与二维码登录

#### 3.7.1 认证设计

- **家长账号**：邮箱/手机号 + 密码（bcrypt），支持多孩子档案挂在家长下。
- **访问控制**：JWT 短时效 Access Token（15 分钟，仅内存/变量，不落 localStorage）+ Refresh Token（30 天，HttpOnly + Secure + SameSite Cookie，服务端可撤销、轮换）。
- **孩子入口**：不单独登录，家长在设备上选择孩子后进入；切换孩子或退出需家长 PIN。
- **家长控制区**（设置、报表、内容审核）二次校验 PIN 或重新输入密码。

#### 3.7.2 二维码登录流程

```
1. 桌面端 GET /api/v1/auth/qrcode
   → 返回 { qr_token, expires_in: 60, deep_link }
2. 桌面端展示二维码，并通过 SSE 订阅
   GET /api/v1/auth/qrcode/{qr_token}/events   (text/event-stream)
3. 家长手机（已登录）扫码 → POST /api/v1/auth/qrcode/scan { qr_token }
4. 手机端弹出确认（显示设备信息：浏览器 + 城市 + IP 段）
5. 确认 → POST /api/v1/auth/qrcode/confirm
6. 服务端生成一次性兑换码，通过 SSE 推送给桌面端
7. 桌面端 POST /api/v1/auth/qrcode/exchange → 换取 Refresh + Access Token
```

**安全约束**：qr_token 一次性、60 秒过期、绑定创建端 IP/UA、扫码端需已登录且限流（每分钟 ≤5 次）、失败 5 次锁定该 token、全程记录登录审计日志。

### 3.9 内容采集子系统（爬虫）

#### 3.9.1 采集目标与数据源优先级

**优先使用「明确开源/公共领域授权」的结构化数据源，其次才是网页抓取。**

| 内容 | 推荐来源 | 授权 |
| --- | --- | --- |
| 汉字拼音、部首、笔画 | 开源数据包（pinyin-data、cnchar 字典、汉典字库） | 需逐一核对 license（MIT / CC 优先） |
| 笔顺动画数据 | hanzi-writer 开源笔顺库（Make Me A Hanzi 衍生） | 需核对字体衍生授权，商用前确认 |
| 组词、例句 | 优先由规则 + 词表生成，或从公开词典（Wiktionary / 汉典）抓取 | CC BY-SA 需署名 |
| 英语单词、音标、释义 | Wiktionary（CC BY-SA）、GCIDE/WordNet（公共领域）、Dolch/Fry 词表（公共领域） | 公共领域优先 |
| 单词配图 | Openverse、Wikimedia Commons、OpenClipart（CC0/PD） | CC0/PD |
| 单词发音 | Wiktionary 音频（CC）或本地 TTS 合成（eSpeak-ng / Azure TTS） | TTS 更安全 |
| 中文故事 | **公共领域文本**（伊索寓言、格林童话早期译本、古诗词）+ **自研原创生成** | 公有领域 + 原创 |
| 英文动画 | **不采集**。外链登记 / 本地上传 / 媒体目录扫描 | 家长自负责 |

**明确禁止**：抓取商业题库站、付费教育平台、视频站点的受版权保护视频、绕过登录/反爬机制的内容。

#### 3.9.2 爬虫工程约束

- 独立 worker 进程，与主 API 进程分离，通过任务表驱动（幂等、重试、死信队列）。
- 遵守 `robots.txt`；声明 UA（含联系方式）；单域名 QPS ≤ 1，随机延迟；失败指数退避。
- 采集结果写入 `crawl_raw` 原文快照 + `content_review` 审核队列，**不直接上线**。
- 字段级去重（hash 校验）+ 来源溯源（记录 source_url、抓取时间、license）。
- 家长后台可查看数据源健康度、采集量、审核积压量。
- 提供"手动录入/CSV 批量导入"作为爬虫的补充与兜底通道。

## 九、风险与合规

| 风险 | 等级 | 应对 |
| --- | --- | --- |
| **内容版权** | 高 | 优先开源/公有领域数据源；所有入库内容记录来源与授权；故事优先原创或公有领域；**视频一律不爬取**，仅外链/本地上传；可疑内容默认 `pending` 待家长审核 |
| **爬虫合规** | 高 | 遵守 robots.txt、限速、声明 UA；不绕登录/反爬；不抓商业题库与视频站；保留来源溯源 |
| **儿童个人信息** | 高 | 数据最小化（不存真实姓名/照片/定位）；数据可导出可删除；公网部署必须 HTTPS；不接第三方统计/广告 SDK |
| **屏幕沉迷** | 中 | 时长上限 + 休息提醒 + 锁屏；提供打印替代路径；不做连续签到强绑定与排名 |
| **内容质量（爬虫噪声）** | 中 | 审核队列 + 字段校验 + 家长可下架；错别字与不适内容一键反馈 |
| **自动评分误判** | 中 | 主观题（跟读、开放问答）交由家长评分，不计入自动正确率 |
| **公网暴露面** | 中 | 限流、登录审计、Refresh 可撤销、依赖漏洞扫描（govulncheck / npm audit） |
| **LLM/AI 依赖** | 低 | 首期规则引擎为主，AI 仅作可选增强（故事生成、错因分析） |

## 附录 B：教材/素材导入通道（MarkItDown）

爬虫之外，再提供一条**离线导入通道**：家长把已有的 PDF / Word / Excel / PPT 教材与词表，用 MarkItDown 转成 Markdown，再由服务端解析器入库（进入 `content_review` 审核队列）。

```bash
pip install "markitdown[all]"
markitdown 一年级生字表.xlsx -o hanzi.md
markitdown 英语单词表.docx   -o words.md
markitdown 启蒙故事.pdf      -o stories.md
```

服务端约定解析格式（Markdown 表格或 YAML Front Matter 声明类型）：

```markdown
---
content_type: hanzi
grade_level: 1
source: 部编版一年级上册
---
| 字 | 拼音 | 组词 | 例句 |
| --- | --- | --- | --- |
| 日 | rì | 日出、日子 | 太阳从东方日出。 |
```

导入后与爬虫内容走**同一套审核流程**，家长确认无误再 `published`。这条路比爬虫更可控，建议作为内容冷启动的主力方式。
